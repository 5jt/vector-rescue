*by Adam Weber*
{ .byline }

With the arrival of Windows 95, I took a leap of faith and installed it on my machine shortly after its release. Sure enough, it worked first time, and found all my hardware etc. But how would it run my DOS apps?

I still use APL\*PLUS PC v.11, and had installed it so that it would run under Windows 3.1. The problem was that after upgrading to Windows 95, I was not able to see APL characters when running in a window. After a little messing around I found the answer in the Properties option in the APL window!

There are several font sizes that DO correctly display the APL character set. These are:

8 x 14 &emsp; 8 x 16 &emsp; 9 x 11 &emsp; 10 x 23

My APL sessions are done in 80 chars, 25 lines, and the above fonts might not work in other configurations. TrueType fonts do not work at all.

In short, if you can’t see proper APL characters in a window under Windows 95, simply try the different font sizes in the properties of the APL window and you might just be in luck! If all else fails, then only the full screen will display the proper characters.

As for printing the characters on an HP Deskjet — no chance!!!
