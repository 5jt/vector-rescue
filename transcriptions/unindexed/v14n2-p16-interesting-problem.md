*From: Ajay Askoolum, 22nd July 1997*
{ .byline }

Given a chess board (8×8 cells), place exactly 16 dots, one in any given cell such that:

1. each row
2. each column
3. each diagonal

is either empty or has exactly 2 dots in it.

This can be judged by APL solution + execution time. (The solution is not unique … but how many solutions are there?)
