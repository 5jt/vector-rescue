*by Richard Smith (when aged 3)*
{ .byline }

The following APL doodles are all the work of one Richard Smith, at the ages shown. They were done on APL\*PLUS/PC, but with the I-APL keyboard layout to make it easier for him to identify the keys. (Reverse is much easier to hit if you don’t need the Alt-combination).

They were snapped by a little function called `ZAP` which simply took a screen copy into a variable named (for example) ZZ041083 (1st birthday in origin-0); Richard was unsupervised for all the examples shown, except for father occasionally sneaking up on the keyboard to `ZAP` anything interesting.

Incidentally we don’t have any APL labels on the keys, but we do have a Hercules+ card installed, so the APL symbols appear correctly on the screen.
