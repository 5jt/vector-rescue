## AFM for APL2/PC

![Photograph of the AFM exhibition stand: a woman behind the counter talks to a visitor, with AFM posters on the wall behind](v6n2-p44-new-product-announcements/afm-stand.jpg)

**The AFM Stand at APL89**

AFM/PC is a single-user version of the AFM file management system which Interprocess Systems Inc. has provided for IBM mainframe environments since 1978. It supports nearly all of the AFM file commands available on the mainframe, and emulates the mainframe library structure on the PC. Both keyed and component files are supported.

AFM/PC works with DOS 3.1 or later, and with APL2/PC 1.0 (or later) in either 16-bit or 32-bit modes. It is priced at $175 with volume dicounts available. For more details, contact Stella Chamberlain on (404) 992-8400, or write to Interprocess Systems, 9040 Roswell Rd, Suite 690, Atlanta, Georgia 30350-1131

## Myriade File System for APL\*PLUS/PC

The Myriade File Manager improves upon the functionality of APL\*PLUS/PC component files by providing numeric or character keyed access, multi-variable components and efficient space reclamation. Components can be created, read and updated in any order.

Myriade can handle very large files (up to 192Mbyte under DOS) with over 2 million components: there is provision for effective management of the file space, and for crash recovery on startup. Full and incremental backups can be taken.

The latest release of Myriade allows 64K of the system to be loaded into EEMS memory, which practically eliminates the overhead on workspace.
