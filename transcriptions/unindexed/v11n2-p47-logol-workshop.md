*notes by Jon Sandles*
{ .byline }

Gareth was showing Twics — a workspace that comes with the Logol suite that allows you to explore and experiment with some of the functionality built into Logol. It also contains some of the functionality that has NOT been built into Logol, because they would like you to find out for yourself why it doesn’t work!! I played with lotsizing and bin-packing routines, and also the least squares Fourier fits.
