## Reviews Section

*introduction by Adrian Smith*
{ .byline }

This Vector includes a brief review of APL\*PLUS/PC version-9. Obviously, this concentrates on the new features available in this release; it is assumed that most readers are sufficiently familiar with the basic product that there is no need to mention existing features and facilities.

Readers might like to note the April 1st release date of IBM’s latest APL2.5 for the RS/6000 workstation and Microwriter AgendA. At the initial price of £99.99 (excl VAT), this is clearly a breakthrough in APL price/performance, including as it does a 64-bit packager, and a set of AP’s to provide full OS/2 Presentation-manager emulation.

We have also received an advance copy of Dyalog APL/386 with the new session manager facilities discussed by John Scholes on page 107. I can confirm the immediate impact made by the new style of session, but I need more time to get to know it in depth. The review will appear in July’s Vector.

Finally, we hope also to review Release 6 of the Powertools/PC product, with the Common User Access tools demonstrated at the March meeting of the Association. This gives APL applications the ability to reproduce the effect of MS Windows, complete with mouse support, pop-up graphics and scrolling windows.
