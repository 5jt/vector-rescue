## Erratum – Function Models

In Vector 18.2 (page 134 is typical) a change to the mapping in Phil’s Unicode font caught out Production in a big way. The symbols are still used consistently, but where you see 1/7 you should really see ∅ and 8/9 and 1/9 are 𝕌 and 𝕀. Finally for 5/9 read 𝕊 throughout. Hopefully, this one will get it right! The ‘January 2001’ version of the font on the Vector website is the correct one. Sorry, Phil.
