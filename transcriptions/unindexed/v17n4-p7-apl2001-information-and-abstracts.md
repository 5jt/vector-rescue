### Conference Site

The conference will be held at Yale University, which is celebrating its 300<sup>th</sup> anniversary. Yale has made important contributions to the development of APL, both directly and indirectly through its graduates and faculty. In addition Yale is an important educational and cultural center with a number of important museums on campus. In many ways it is an ideal place to host our conference.

### Abstracts of Papers

*A Canon for the Representation of Multivariate Arrays In the APL2 Computing Language, Richard Drexel Stockbridge.* A uniform structure for multivariate data constructs that describes its own contents. A library of APL2 functions perform analytical, archival, and graphical operations on these structures.

*Adage: A Dynamic APL GUI Equation Solver, Stephen M. Mansour* ADAGE, (A Dynamic APL GUI Equation solver), allows the user to solve a single multivariate equation when values are supplied for all but one of the variables. Examples from the mortgage industry are explored.

*Embedding a Tcl Web Server into APL, Dr. Tilman P. Otto.* Tcl, Tool Command Language, is a script language and an extensible interpreter. The many available Tcl extensions for GUI, network, database, HTML and XML support, make the combination of APL and Tcl very attractive.

*Good Taste in Color and Soft Palettes, Devon McCormick.* Contrasts the exploration of a problem in a non-array-processing language, Java, and 2 array-processing languages, APL and J. The task is to generate a 256-color palette for a bitmap where the colors cover a full range of available hues evenly.

*Operation Arrays in APL, Jacob Brickman.* Explores the many ramifications of allowing arrays of APL functions, operators, and future syntactic classes. How operation arrays relate to Object-Oriented Programming, the implications of side effects, scoping, memory models and synchronization.

*Suggestions for a Method of Analyzing Binary Images Using Langlet's Parity Logic, Stuart Smith.* Describes an extension to the system of parity logic operations developed by Gerard Langlet and subsequently elaborated by Michael Zaus. The algorithms and the programming examples are coded in Q'Nial.

Is There a Way to Combine Array-processing and Object-Oriented Programming? Georg Reichard. It is shown that, with today's APL interpreters, it is possible to combine array-processing and object-oriented programming on a very high level of abstraction.

*Replacing an Explicit Loop by the Each Operator, Joseph Burchfield, Samir Lipovaca.* A comparison of explicit loops and array operations focusing on the each operator.

*J and Sports Betting, Pablo Landherr.* This paper discusses how J was used to describe the math in one area of sports betting to develop an automatic odds generator and to test this generator using robots.

*Correctly Detecting Intrinsic Type Errors in Typeless Languages such as MATLAB, G. Pramod, V. Joisha.* This paper presents a methodology for inferring a variable's type in languages which do not explicitly declare type. The techniques are demonstrated in MATLAB.

*Array Form Representation of Idiom Recognition System for Numerical Programs, Hiroyuki Sato.* PSE (problem solving environment) is an approach to providing high-level abstract functions. Term rewriting theory is applied to the problem in Fortran 90/95 matrix manipulations.

*Graph Coloring Algorithms in J, Howard A. Peelle.* Four basic algorithms for coloring non-directed graphs are described in J, along with tools for generating adequacy matrices for such graphs and testing them

*D2Cell Data Mining Utility, John Manges.* D2Cell is a Data Mining Utility for Windows based PCs which downloads custom Mainframe DB2 data directly into Microsoft Excel. A Wizard will automatically generate SQL for processing or the user may create his own SQL statements

*An Array-Oriented (APL) Wish List, Jim Lucas.* Several proposals for extensions to APL are proposed, including event objects, ragged arrays, enumerated classes, rank, pad and fill operators, and 'where' a new control structure.
