## IBM APL2/PC (including 32-bit APL and free runtime)

This is an almost complete APL2 interpreter for the PC. The product was announced in the UK on 14th November 1988, and will be available early in 1989.

It includes a 32-bit version of the interpreter for use on 386-based machines, and the 16-bit version has the option of a 'packager' which produces a .EXE file from your APL workspace which you may freely distribute.

Auxiliary processors are included for full-screen management (AP124 style), file handling, communications and so on.

The interpreter was demonstrated at APL-ication, both in 16-bit and 32-bit versions. The price is £348.

## STSC APL\*PLUS II

A full 32-bit rewrite of APL\*PLUS/PC with nested arrays as per the mainframe product. The cost is approximately £2,000 ... see the entry for Cocking and Drury in the Product Guide.

## Adelphi APL to Oracle Interface for APL\*PLUS/PC

Tibor Horvath (Arlington Associates) announces Adelphi to provide PC users access to an SQL database from APL. It connects APL\*PLUS/PC to the Oracle relational database. The product consists of a compiled routine which links APL to Oracle, and APL functions for interacting with the database. SQL statements are passed as arguments to these functions, and data is transferred between the database and the workspace using one APL variable for each field.

Adelphi requires APL\*PLUS/PC version 3.0 or higher, Oracle version 5.1 or 5.1A, IBM PC with 640K, plus 896K extended memory, and a fixed disk.

It is available from August 31st 1988, at a cost of $195. Contact:
