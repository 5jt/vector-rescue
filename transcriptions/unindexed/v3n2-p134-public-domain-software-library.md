## Software contributions

Any item of use or interest to APL programmers is welcomed in the library. For a six month experimental period the operation of the library will be kept as simple as possible. After that extensions may be made.
The initial scheme is:

1. The library item is a PC compatible disk (9 sector 360K).
2. Each software contribution should be accompanied by a document in the format below which:
   - a asserts the software is yours to give and authorises the British APL Association (BAA) to give it away on your behalf.
   - b indemnifies the BAA and its members against claims from third parties for breach of copyright, libel or breach of the law.
   - c contains a description of the disk and a one line description of each file on the disk (for the catalogue).
3. The BAA make no claim or warranty about the content of the library.

The material must be supplied on a DOS-format disk which can be copied on a PC compatible machine. The contents of the files may be in any format for any variety of APL. Documentation should, if possible, be provided on the disk.

## Public Domain Software Library

### APL 90 Interpreter for Macintosh

Ref: 86001  
Machine: Macintosh. Donor: J.J. Girardot  
Documentation: On line & 2 pages. Size: 2 Disks.

APL 90 is a complete APL system for Macintosh, and includes some of IBM's APL2 facilities (strand notation, nested arrays, user defined operators . . .).

### Life

Ref: 86002  
Machine: IBM PC. Donor: P. Chapman  
Documentation: On line. Size: 1 Disk, 8 Files, 40K.

A version of Conway's game of life for the IBM PC. Hundreds of times faster than previous version. 65532 by 65532 universe. Full editing and library functions. Some sample patterns. See tutorial volume of conference proceedings for background. (RUNCODE Life by Paul Chapman).

*Ed: Great fun.*

### Fluctuation analysis of multichannel spectra

Ref: 86003  
Machine: IBM PC, APL: APL\*PLUS/PC. Donor: Claude Bastian  
Documentation: On Line. Size: 1 Disk, 1 File, 8K.

Workspace WALSH – Analysis/condensation of counting fluctuations in multichannel spectra or time series. Further description in APL 86 proceedings pages 50 to 58.

### Free software from APL385

Ref: 86004  
Machine: IBM PC, APL: APL\*PLUS/PC. Donor: Adrian Smith  
Documentation: £50 or $75. Size: 1 Disk, 13 Files, 270K.

- "Is it a Plane: is it a Bird?" (Expert System Shell)
- Digital Cuckoo Clock (Honest)
- File Utilities (Function Swopping and DOS files to and from APL)
- PASCAL-Written DOS file lister.

Documentation is available from: APL385, Brook House, Gilling East, York, England

*Ed: Lots of useful functions.*

### Piano

Ref: 86005  
Machine: IBM PC, APL: APL\*PLUS/PC. Donor: G. Langlet  
Documentation: On Line. Size: 1 Disk, 1 File, 3K.

Play the PC like a piano.

*Ed: OK for nursery rhymes.*

### Frame

Ref: 86007  
Machine: IBM PC, APL: Sharp APL/PC. Donor: Robert Pullman  
Documentation: 11 Pages. Size: 1 Disk, 2 Files, 67K.

Editing multidimensional numeric arrays.

### Get/put files

Ref: 86008  
Machine: IBM PC, APL: APL\*PLUS/PC. Donor: M Kent  
Documentation: On Line. Size: 1 Disk, 2 Files, 16K.

Functions for manipulating data in APL\*PLUS files by "item name", rather than by component number. The associated file structure is called a "Get/Put" file, whence the workspace name "GP".

### Binary Combinations

Ref: 86009  
Machine: IBM PC, APL: APL\*PLUS/PC. Donor: Otway Pardee  
Documentation: On Line. Size: 1 Disk, 1 File, 2K.

Very fast method for generating the binary image of combinations. Useful and fast where the number of combinations is large. Can easily be adapted to generate the combinations in subsets. This method has only one explicit APL loop.

*Ed: Needs assembler for real speed.*

### Workspace Lister

Ref: 86010  
Machine: IBM PC, APL: APL\*PLUS/PC. Donor: Roger Harper  
Documentation: On Line. Size: 1 Disk, 1 File, 14K.

Pretty-printer for APL\*PLUS workspaces, both functions and variables, with index and paginations. Assumes an Epson LQ1500 printer, but can be converted to other printers.

### TEXT

Ref: 86011  
Machine: IBM PC, APL: APL\*PLUS/PC. Donor: Ian Feldberg  
Documentation: On Line. Size: 1 Disk, 7 Files, 330K.

Typesetting for the IBM-PC using APL\*PLUS. Documented in APL 86 conference proceedings.

*Ed: PC users will need GRAPHPAK for the PC, ref: 86012.*

### Reverse Polish APL Intepreter Model
