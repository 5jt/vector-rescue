*From: Andy Pole, Duke University, Durham, North Carolina.*
{ .byline }

**Labelling (Education Vector, July 1991, p.30)**

For people with APL\*PLUS/PC there is a utility workspace provided called FORMAT which includes routines to centre a title, label rows, label columns, left and right justify arrays of strings. Details can be found in the documentation (for release 8 see Chapter 6, Aids to Formatting, in the Formatting section). For dealing with segmented strings, removal of blanks, text replacement etc. there is a collection of assembly language routines in the workspace ASMFNS. A useful feature of the documentation (see “Workspaces” in the manual) is that for several examples equivalent APL expressions are given. Another source of useful APL idioms for all sorts of operations is the FINN APL idiom booklet.
