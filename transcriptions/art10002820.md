In VECTOR 7.3 pp 130-135, Ray Cannon proposed some functions in APL\*PLUS/PC to be able to use the mouse. These functions were very much welcome for me, but I slightly modified them as follows.

The mouse always works in pixels, that is the screen is divided in 200 lines of 640 columns even in text mode. In that case, the values jump by 8 (0 8 16 24 .... 632 and 0 8 .... 192). That is why Ray divides the cursor position values by 8 (`MS∆Q MS∆QCU MS∆QR MS∆WIN MS∆CU`:0.125 x or 8 x) to return 25 lines and 80 columns (1 character “boxes”).

But you can design different boxes. Suppose you have a menu bar at the top of the screen; it uses 8 pixel’s lines (one text line) and you have 10 entries (each 64 pixel’s columns). So the returned cursor position should always be 0 for the line and 0 1 2 .... or 9 for the columns (top left corner is 0 0). The modified functions allow to specify the size of the boxes. If two values are given they represent the y and x values (lines and columns), a single value will apply to both y and x. In text mode one will generally use 8 (as Ray did).

I have also introduced `⎕IO = 1` as local to the mouse functions. One could even go further by choosing the mouse shape and colour, but that is another story.

Finally I want to point out that I got some problems with the mouse in EGA graphic mode:

1. the cursor moves down to line 200 but not to line 357 or so of the EGA mode,
2. there is conflict with `⎕GWRITE` and
3. there is conflict with `⎕GPRINT`. I haven’t seen version 10 of APL\*PLUS/PC, so I do not know if these problems exist with the builtin mouse support.

The function `GENERAL` uses the modified mouse functions. `barremenu` provides a screen with a top line menu: Help File Exit System Do and two information boxes. Selection is done either by clicking with the mouse left button or by typing the first letter of the choice. The mouse window is restricted to the first line.

```
    ∇ MS∆INIT cu;rc
[1]  ⍝ Initialize mouse ... global ⍙mouse←1 if OK ... else 0
[2]  ⍝ cu is the cursor type ... 0=mouse block; 1=hardware
[3]   rc←0 ⎕INT 51 ⋄ ⍙mouse←0≠1↑rc ⋄ →⍙mouse↓0
[4]   →cu↓0 ⋄ rc← 10 1 ⎕INT 51
    ∇
```

```
    ∇ MS∆SHOW;r
[1]  ⍝ Show mouse cursor
[2]   →⍙mouse↓0 ⋄ r←1 ⎕INT 51
    ∇
```

```
    ∇ MS∆HIDE;r

```
