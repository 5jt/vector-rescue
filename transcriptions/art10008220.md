by Adrian Smith

Rather than upgrading your copy of APL\*PLUS/PC to version 4.2, you might find the following locations useful. If you have access to a utility such as PC Tools or ‘Norton’ you can simple edit the .EXE file directly in hex; otherwise the little function below will do the trick:

```apl
    CUSTOM BANNER INSTALLATION FOR APL*PLUS/PC
    ==========================================

FI←'ZAP7.EXE'   ⍝ .... set filename to xxxx.EXE

BNR←123940 ⋄ SER←4126 ⋄ VER←100957    ⍝ Set up for Vn5
BNR←140932 ⋄ SER←5150 ⋄ VER←114344    ⍝ Set up for Vn6
BNR←153796 ⋄ SER←6175 ⋄ VER←124716    ⍝ Set up for Vn7

FI PUT∆BAN ANY∆CHAR∆VEC   ⍝ ... update banner details

)OFF              ⍝ .... go and try it!


    FI PUT∆BAN BANNER
    -----------------

[1]  ⍝ PATCH IN BANNER TO FILE FI .....

[2]   FI ⎕NTIE ¯1
[3]   (631↑BANNER,⎕TCNL,630⍴⎕TCNUL)⎕NREPLACE ¯1,BNR
[4]   (6⍴⎕TCNUL)⎕NREPLACE ¯1,SER
[5]   (3⍴⎕TCNUL)⎕NREPLACE ¯1,VER
[6]   ⎕NUNTIE ¯1
    ∇
```
