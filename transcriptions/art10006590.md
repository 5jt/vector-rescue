*From: Howard A. Peelle, July 1996*
{ .byline }

In [1] Norman Thomson resurrects Sylvester’s algorithm for converting a "vulgar fraction" (decimal between 0 and 1) into a list of "unit fractions" (or integer reciprocals). Here, Sylvester’s algorithm is recast again in J for perspicuity.

First, compute the largest unit fraction less than the input:

```text
   unit =. >. &. %
```

For example:

```text
   unit Fraction =. 0.67296
0.5
```

Use this to decompose the input into the largest unit fraction and the "error" term:

```text
   decompose =. unit , (- unit)
```

For example:

```text
   decompose Fraction
0.5 0.17296
```

Use this to extend any such list by decomposing the last term:

```text
   extend =. }: , decompose@{:
```

For example:

```text
   extend 0.5 0.17296
0.5 0.1666667 0.006293333
```

And, finally, repeat it:

```text
   extend^:3 Fraction
0.5 0.1666667 0.006289308 4.02516e_6
```

The integer reciprocals are obtained easily. For example:

```text
   % extend^:3 Fraction
2 6 159 248437
```

Also, note the identity:

```text
   Fraction = +/ extend^:3 Fraction
1
```

Further, this applies to a vulgar mixed fraction as well:

```text
   extend^:6 Mixed =. 3.67296
1 1 1 0.5 0.1666667 0.006289308 4.02516e_6
```

And to negative vulgar fractions (between `_1` and `0`):

```text
   extend^:3 -Fraction
_1 0.25 0.07692308 0.0001169231
```

And to real, non-empty arrays:

```text
   extend^:3"0 Fraction,-Fraction
0.5 0.1666667 0.006289308    4.02516e_6
 _1      0.25  0.07692308 0.0001169231
```

All this may be embodied in a program to return the leading integers (without the error term) whose unit fractions approximate the vulgar fraction input:

```text
   sylvester =. [: }:"1 [: % extend@]^:["0
```

For example:

```text
   3 sylvester (+,-) Fraction
 2 6 159
_1 4  13
```

Also in [1] Norman Thomson codes a similar algorithm to represent a fraction (decimal) in a given number base. Here it is expressed simply:

```text
   f =. * 1&|
```

For example:

```text
   <. 5 f^:(i.6) Fraction
0 3 1 4 0 3                     NB. +/0 3 1 4 0 3 * 5 ^ -i.6
```
