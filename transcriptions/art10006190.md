*by Tapio Nummi*
{ .byline }

The aim of this note is to show how to make the Cholesky decomposition effectively by using array operations provided by APL. The Cholesky decomposition for a positive definite matrix **A** can be written as

> **A** = **R′R**

where **R** is an upper triangular matrix. The algorithm is given by

> *r*<sub>1*j*</sub> = *a*<sub>1*j*</sub> / √*a*<sub>11</sub>

if *j* = 1, 2,…, *n*. If *i* = 2,…, *n*

> *r*<sub>*ii*</sub> = √( *a*<sub>*ii*</sub> − Σ<sub>*k*=1</sub><sup>*i*−1</sup> *r*<sub>*ki*</sub><sup>2</sup> )  and  *r*<sub>*ij*</sub> = ( *a*<sub>*ij*</sub> − Σ<sub>*k*=1</sub><sup>*i*−1</sup> *r*<sub>*ki*</sub>*r*<sub>*kj*</sub> ) / *r*<sub>*ii*</sub>

when *j* = *i* + 1,…, *n*.

As an example we consider the Cholesky decomposition for a definite 3 × 3 matrix **A**. This yields

> **R** =
>
> row 1: *a*<sub>11</sub>/√*a*<sub>11</sub>, *a*<sub>12</sub>/√*a*<sub>11</sub>, *a*<sub>13</sub>/√*a*<sub>11</sub>
>
> row 2: 0, (*a*<sub>22</sub> − *r*<sub>12</sub>*r*<sub>12</sub>)/√(*a*<sub>22</sub> − *r*<sub>12</sub><sup>2</sup>), (*a*<sub>23</sub> − *r*<sub>12</sub>*r*<sub>13</sub>)/√(*a*<sub>22</sub> − *r*<sub>12</sub><sup>2</sup>)
>
> row 3: 0, 0, (*a*<sub>33</sub> − (*r*<sub>13</sub><sup>2</sup> + *r*<sub>23</sub><sup>2</sup>))/√(*a*<sub>33</sub> − (*r*<sub>13</sub><sup>2</sup> + *r*<sub>23</sub><sup>2</sup>))

By using APL the first row of **R** is

```apl
R[1;)←A[1;]÷A[1;1]*0.5
```

For the second row we need

```apl
B←1 1↓A-R[1;]∘.×R[1;]
```

which gives

> **B** =
>
> row 1: *a*<sub>22</sub> − *r*<sub>12</sub><sup>2</sup>, *a*<sub>23</sub> − *r*<sub>12</sub>*r*<sub>13</sub>
>
> row 2: *a*<sub>32</sub> − *r*<sub>13</sub>*r*<sub>12</sub>, *a*<sub>33</sub> − *r*<sub>13</sub><sup>2</sup>

Then the second row of **R** is

```apl
R[2;]←¯3↑B[1;]÷B[1;1]*0.5
```

For the third row we make new **B**

```apl
B←1 1↓B-(1↓R[2;])∘.×1↓R[2;]
```

Then by using

> **B** = (*a*<sub>33</sub> − *r*<sub>13</sub><sup>2</sup> − *r*<sub>23</sub><sup>2</sup>)

we easily compute the third row as

```apl
R[3;]←¯3↑B[1;]÷B[1;1]*0.5
```

As an APL function

```apl
    ∇R←CHOLESKY A;B;I;V;N
[1]   R←(⍴B←A)⍴~I←1 ⋄ N←1↑⍴A
[2]  L:R[I;]←(-N)↑V←B[1;]÷B[1;1]*0.5
[3]   B←1 1↓B-V∘.×V
[4]   →(N≥I←I+1)/L
    ∇
```

The function consists of only one loop and the APL code to iterate is rather minimal. Therefore this function is effective also for large positive definite matrices.

```apl
      +C←(3,3)⍴1 2 3 2 20 26 3 26 70

1  2  3
2 20 26
3 26 70

      CHOLESKY C

1 2 3
0 4 5
0 0 6
```
