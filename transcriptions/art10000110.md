## Significance Tests

Given the stock market collapse, we might be interested to know whether 1988’s figures are the same as 1986’s. If they are, has the market recovered?

If we are willing to assume that the data is normal and independent then we can use a parametric test. We first test the data to see if the variances are the same with a variance test. This is based on the ratio of the two variances:

```apl
    M[⍳12] VARRATIO M[23+⍳12]
0.5579
```

The value has to be compared to the F Distribution to see if it is significant. Given the value is less than one, we can take the reciprocal test is against F on 11,11 degrees of freedom.

```apl
    11 11 FTAIL1 ÷M[⍳12] VARRATIO M[23+⍳12]
0.1737
```

The probability is fortunately in the central region of the distribution and hence we can assume the data have similar variances. We can now carry out the two sample t test.

```apl
    M[⍳12] TWOSAMT M[23+⍳12]
¯5.092
```

The value obtained should be compared to the t distribution on 22 degrees of freedom.

```apl
    22 TTAIL M[⍳12] TWOSAMT M[23+⍳12]
0.9999789111
```

The result indicates that the populations are different, since the probability is in the tail of the distribution. It may be that one is doubtful about the normal assumption? Therefore a non-parametric test might be more sensible. The Mann-Whitney test is an appropriate choice.

```apl
    M[⍳12] MANNWHIT M[23+⍳12]
26
```

This value could be compared to the appropriate table but if the analyst is willing to take the normalised value, he could compare with the t distribution as an approximation. The sample is relatively large.

```apl
    M[⍳12] MANNWHITTS M[23+⍳12]
¯2.655811238
```

This produces the normalised value of the test statistic. The probability value would be

```apl
    22 TTAIL M[⍳12] MANNWHITTS M[23+⍳12]
0.9927809917
```

Fortunately a similar result as before. We might consider comparing the three years assuming the values are random observations from the years, although this is a little doubtful. The one way ANOVA test can be used to test whether the three years differ.

```apl
    J←(12 12 12/1 2 3) ONEWAY M
    J
 2     14651.35035     7325.675175      11.58166525
33     20873.27475      632.5234773      0
35     35524.6251         0               0
```

We have assigned the result to *J* so that we can test the variance ratio against the F distribution.

```apl
    J[1 2;1] FTAIL1 J[1;4]
1.547062728E¯4
```

A low probability, implying difference, as might be expected.

## Time Series

The above analysis was possibly not wholly appropriate since we know the data is a time series. Hence it would be sensible to treat it as such. We can then obtain the Moving Average to see whether there is a trend.


This produces a moving average whose values fall between the observations since the period 12 is even. It is more usual to produce the Centred Moving Average for even data.


With this it is possible to calculate the seasonal effects and hence remove them from the data. The seasonally adjusted moving average can be obtained for both an additive model for seasonal effects as well as multiplicative. ## Linear Regression

In this data we might be interested to see if there is a relationship between Turnover and Household and the number of employees. Obviously as prospective franchise buyers we wish to predict Turnover.

Can we predict Turnover from Households? The model would be a linear regression:

T = b0 + b1 H

The model is fitted using a set of routines `REGLINEST` and `REGLINRESID` etc., but we can use `REGLINREP` to get a brief report. We store the results again, to test against the F distribution.

```apl
    FP←⍎,REGLINREP DATAF[;1 2]
    REGLINREP DATAF[;1 2]

EST REGRN. COEFF(S). 126.51 3.5443E¯3
EST STAN. ERROR(S).   34.508 5.6596E¯3
EST ERROR VARIANCE.  13097
EST COEFF. OF DETERMINATION  0.02725
ANALYSIS OF VARIANCE:-
SOURCE           SS            DF       MS          F-RATIO
REGRESSION   5136.6             1       5136.6       0.39219
RESIDUAL          1.8336E5     14       13097
TOTAL             1.885E5      15       12567
```

The result is a little disappointing, apparently Household on its own does not account for a significant amount of variation in Turnover.

```apl
    FP[2 6] FTAIL1 FP[4]
0.5412
```

Indicating that the model is not significant.

## Multiple Regression

Is prediction of Turnover better if we add Staff Numbers to the model? The model is now a multiple regression:

T = b0 + b1H + b2S

We have a set of regression functions which enable us to do this (`REGEST`, `REGRESID` etc). Again we can use the reporting function `REGREP`.

```apl
    FP←⍎,REGREP DATAF,1
    REGREP DATAF,1
EST. REGRN. COEFF(S). 1.1239E¯3 0.25404 ¯29.243
EST. STAN. ERROR(S).  1.8005E¯3 0.022514 17.587
EST. ERROR VARIANCE. 1306.7
EST. COEFF. OF DETERMINATION  0.90988
ANALYSIS OF VARIANCE:-
SOURCE             SS            DF       MS          F-RATIO
REGRESSION          1.7151E5      2       85755         65.628
RESIDUAL       16987             13        1306.7
```

We have assumed a mean, hence the column of 1 in the matrix.

```apl
    FP[2 6] FTAIL1 FP[4]
1.608E¯7
```

The result is significant. Fitting both variables seems to account for a large proportion of the variability in Turnover.

## Polynomial Regression

Instead of adding Staff Numbers, we could have tried using the polynomial model,

T = b0 + b1H + b2H\*2

A set of Polynomial Regression functions exist in basic Statistics - `REGPOLYEST` etc. Using `REGPOLYREP` to fit a quadratic, we get:

