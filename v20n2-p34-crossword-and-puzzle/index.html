New Crossword¶

Across¶

  1. Start with a blank slate
  2. Preserve your work
  3. (|K)×(⌈RL), expressed as words
  4. The location in vector E of the elements in K[⍳VA]
  5. The magnitude of the elements of the cumulative sum of the reciprocal of S
  6. 2↑⍎'''R5↓3'''
  7. ⎕__, the current “seed” of the random number generator
  8. Release storage from suspensions
  9. List of all suspended identifiers
  10. 1÷VEC
  11. (ρS)ρ1
  12. )___ when done
  13. (+/E)ρYPV for positive integer vector E, scalar YPV
  14. ⎕__, for timing algorithms
  15. List of all suspended functions
  16. MP+1|-MP
  17. Delete a stored workspace
  18. Branch to line labelled MB
  19. One random element of ⍳W
  20. (V⍳AC)=⎕IO+ρV
  21. (LTO↓JS),LTO↑S for positive scalar LTO
  22. ⎕IO++/∧\L≠OV for vector L, scalar OV
  23. 0 if RLM=I, 1 if RLM>I, ¯1 if RLM<I
  24. ((POP,(ρN)-POP)/1 0)/N
  25. 2⍟×\XSρ2 in origin 1
  26. ∨/BD∘.=PAYRL for vector PAYRL

Down¶

  1. +\(1++/∧\S≠5)ρ1 for vector S, ⎕IO=1
  2. Names of arrays in the workspace
  3. V[LI+⍳CE] for scalar LI
  4. Format to E decimal places ...
  5. A-A×⌊(|R)÷A
  6. (E+F×RK)÷F
  7. (⌽⍳ρρLSTC)⍉LSTC
  8. Delete from active workspace
  9. ⎕__, all available characters
  10. Cumulative product of SV
  11. Divide into R the lesser of EE or S
  12. Replace active workspace
  13. Number of identifiers tracked in the active workspace
  14. (⌈MTRX[;1])=(⌈MTRX[;2]) for two-column MTRX
  15. (~FIR∊LPP)/FIR
  16. ⎕__, maximum number of significant digits to display
  17. Retrieve objects without erasing or over-writing current objects
  18. V+.×⌽I*(⍳ρV)-⎕IO for scalar I
  19. Name of active workspace
  20. (⍳ρOA)=______ to flag first of each distinct value in vector OA
  21. Branch to line labelled L if ...
  22. A random number from 1 to J-B , in origin 1
  23. The elements (simple vector) of the first V items of nested vector R in APL2 notation
  24. M[(1+ρM)-⍳ρM] in origin 1
  25. ⎕__, the names of workspace objects
