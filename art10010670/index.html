Densities Well Suited for Statistics Problems

Vector 7:2, page 118

mathematics and statistics education

Transcribed from the printed issue; not yet reviewed. Read it in the PDF of the issue, page 118

by Dietrich Trenkler, University of Osnabrück, West-Germany

Introduction¶

Devising examinations in Statistics is a tedious thing to do. For instance, understanding the meaning of the Central Limit Theorem definitely is a goal, but finding continous distributions for which the student can easily compute expectations and variances is hard to do by trial and error. So why not let the computer do the job. In this paper we introduce several APL programs written in APL*PLUS/PC to help in these circumstances. We hold that this is a further step in the direction of generating examinations which at the same time cover a broad range of topics, are less prone to errors and minimize the efforts on behalf of the instructor.

The Problem¶

Let us be given a function f defined by

f(x) = a2x2 + a1x + a0,   α ≤ x ≤ β,
f(x) = 0   else.

Our aim is to give some guidelines for choosing the coefficients ai such that

  • f is a probability density function (p.d.f) and
  • they are sufficiently smooth to ease further computations.

There are two sufficient and necessary conditions for f to be a p.d.f.:

(i) f(x) ≥ 0 for all x, and
(ii) ∫αβ f(t)dt = 1.

Condition (ii) is equivalent to

2a2(β3 − α3) + 3a1(β2 − α2) + 6a0(β − α) = 6.   (1)

To guarantee that f meets condition (i) it is necessary that

f(α) ≥ 0 and f(β) ≥ 0.   (2)

But this is not sufficient if f has a minimum in (α, β). It is easy to see that f has a global minimum (maximum) in x0 = −a1/2a2 if a2 > 0 (a2 < 0). So we impose the restriction f(x0) ≥ 0 which is equivalent to

4a0a2 ≥ a12   (3)

whenever a2 > 0 and −2a2β < a1 < −2a2α.

Having chosen α, β, a2, a1 and a0 one can compute expectations associated with the distribution given by f from

E[Xn] = a2/(n+3) (βn+3 − αn+3) + a1/(n+2) (βn+2 − αn+2) + a0/(n+1) (βn+1 − αn+1)
= A / ((n+3)(n+2)(n+1))   (4)

where

A = a2(n+2)(n+1)(βn+3 − αn+3) + a1(n+3)(n+1)(βn+2 − αn+2) + a0(n+3)(n+2)(βn+1 − αn+1).

The distribution function F is given by

F(x) = 0,   x < α,
F(x) = a2/3 (x3 − α3) + a1/2 (x2 − α2) + a0(x − α),   α ≤ x ≤ β,
F(x) = 1,   β < x.

These formulas can be used to compute variances and percentiles. However, computing percentiles is hard unless a2 ≠ 0 and a1 = a0 = 0 or a2 = 0. Then we get for 0 ≤ p ≤ 1

F−1(p) = ∛(α3 + 3p/a2),   a2 ≠ 0, a1 = a0 = 0,
F−1(p) = −a0/a1 ± √((a0/a1 + α)2 + 2p/a1),   a2 = 0, a1 ≠ 0,   (5)
F−1(p) = α + p/a0,   a2 = a1 = 0.

The Programs¶

Starting point in program GENERDENSITY is criterion (1). Using SUMUP2 we first find a matrix of integers z2 ≤ z1 ≤ z0 such that z ≤ zi for some integer z fixed in advance and z2 + z1 + z0 = 6. This number z has been set to ¯24 since experience has shown that in this way WS FULL problems can be avoided on the author’s PC. Then using PERM all 3! = 6 permutations of its columns are generated. This way, there may be some redundancy but DEDOUBLEROWS at the end of the program truncates all duplicate lines. The numbers

a2 = z2 / 2(β3 − α3),   a1 = z1 / 3(β2 − α2),   a0 = z0 / 6(β − α)

are potential coefficients. To guarantee smooth numbers it is checked if mai is integer for some positive integer m. Thus, setting m = 4 yields numbers like −2.25, 3.5 or −3 for instance. Finally, those rows of the matrix are extracted which fulfill criteria (2) and (3).

Programs EXPECTATION and DISTRIBUTION can be used to determine E[Xn] and F.
