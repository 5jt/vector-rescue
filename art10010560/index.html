J-ottings 42: I (continue to) Spy with verylittle J ... by Norman Thomson

Waybackin J-ottings 25, (the I-spy bookof J) I described the basis of the cryptography which underlies the security of manyof the millions of web transactions which take place every minute out in cyberspace. Such cryptographic systems based on substitution codes depend on using public and private keys. Although an identical techniqueis used for sending and receiving messages,it is nevertheless safe to broadcast one s public key to allow any sender to mail you encrypted messages, since only you possess the private key whichis essential to decrypt them. This property makes such codes non-reciprocal, Reciprocal coding techniques are more primitive, and trade off the simplicity of doing the same thing to encrypt and decrypt against the requirementthat the single underlying key must be kept secret between all communicating parties.

Oneof the best knownof these techniques uses the so-called Vigenére tables after a sixteenth century French diplomatof that name. The idea is that the communicating parties share a table of alphabetic characters which resolve a pair of characters into a single character. 26 by 26 blocks take quite a lot of space, so I shall demonstrate the principle with the six-character alphabet ABCDES . To make a Vigenére table, choose a word such as BED whichleadsto a table keyword "BEDACS in whichthe characters not in the keyword are appended in alphabetic order. The table keyword then serves as row and column headersfor the Vigenére table. To makethe bodyofthe table, start with the table keyword reversed and the remaining rows progressively shifted to theleft :

norumoe PONOHnUMULY AnNADHAOYPD Hom oran DmUOPaAnw AO PANaH Upaunemn

Both the encrypt and the decryptofthe letter pair EC is then B. No doubt you can already glimpse how well J is adapted to producing suchtables!

Sorting the rows and columnsinto alphabetic order is only a considerationif the table is to be displayed for human as opposed to computeruse. Witha six-letter alphabet, even this is hardly worth while, but witha full alphabet of 26 letters it would certainly be desirable. Alphabetic row ordering using the table keywordis achieved by

order=.({~/:) &tkey

and columnordering by doing the sameto the transpose, so thatthe form of vtab in which the row and column headings are both 'abcdes is given by

vgrade=.order&/:@:order lordvtab=.vgrade vtab basdec aecsbd scbeda dseacb ebdcas cdabse

A Vigenére cipher can be made more secure by performing a final alphabetic shift using a further key,call it a shift key :

skey=.3 shift=.dyad :'((#alph)|x.talph i.y.){alph'

The price of this extra security is that the encryption algorithm is no longer reciprocal. However, inverting the shift is simply a matter of applying minus to the shift key, so that the total operation is confirmed by

]x=.skey shift sad encrypt quick a Lazy dog txpgqyi miedjajc sad encrypt (-skey)shift x quick a Lazy dog
