Printing APL Matrices

Vector 6:1, page 64

programming techniques applications

Transcribed from the printed issue; not yet reviewed. Read it in the PDF of the issue, page 64

Jerry M. Brennan, Jennifer E. Daly, and Lawrence H. Nitz

Introduction¶

Existing APL matrix printing capabilities are inadequate in terms of labelling and formatting for all but the simplest applications. Matrices that are larger than the page width of the printer or screen (typically about 80 columns) are wrapped, causing a loss of the original column structure and limiting the usefulness of many APL routines.

This formatting drawback coupled with the lack of column labels in default APL printing programs can result in confusing and aesthetically unsuitable numeric printouts. Therefore, the need exists for a matrix printing program that can present numeric matrices in labelled, columnar formats that are appropriate for business, financial, and statistical applications.

MPR is a matrix printer function that produces a compact, labelled printout of numeric matrices with user-specified row and column labels. (MPR was first used in the menu-driven statistical package ‘Stat 1: A statistical toolbox’ by Jerry M. Brennan and Lawrence H. Nitz, 1988, Kailua, Hawaii: Sugar Mill Software Corporation.) With MPR, matrices of any size can be printed in their entirety since values and labels are printed in segments as is common with other software. Also, certain values can be suppressed, allowing matrices such as ANOVA summary tables or financial reports to be printed with, for example, unnecessary zeros eliminated.

MPR is flexible, allowing considerable user customisation. Default settings include automatic determination of the minimum number of decimal places within each column, suppression of decimal points for integer columns, and default row and column labels. Settings can be changed with the global variables ∆NDEC, ∆LLEN, ⎕PW, and ∆PL. These environment variables are available as preset defaults or can be passed to the routine dyadically (see below for detailed instructions).

Such customisation represents a significant advantage of MPR and supports various applications of the program. For instance, MPR allows the user to print a series of different tables without explicitly formatting each combination of rows and columns, because the correct format for each matrix is automatically determined based on present default settings. This feature is currently accessible in spreadsheet programs such as Lotus 1-2-3, Excel and Quattro, but is not available as a system function in APL.

MPR in APL¶

MPR is a ambivalent function. The right argument consists of the data matrix to be printed. The optional left argument may contain:

  1. row labels
  2. column labels
  3. maximum number of decimals
  4. maximum label length
  5. page width
  6. maximum number of rows in each printed block.

MPR may be used monadically or dyadically. In the monadic instance, the program generates default row and column labels

R2     .11  57.67  89.70  73.09 100.62  78.90  13.22 69.90 295.10 197.90
R3  114.28 223.70  95.93 271.23 291.53 229.78 245.23   .00  34.63  79.31
R4  100.94 108.00 206.75 385.47 196.00    .00    .00   .34    .79    .47

In the dyadic mode, row and column labels are passed to the program two ways:

(a) through user-created variables
(b) as a character string within quotation marks with rows first and columns second.

In the latter instance, the symbols ⊢ and ⊣ (i.e. left tack and right tack) are used to delimit row labels while ⊂ and ⊃ (i.e. implication and reverse implication) indicate column labels. The symbol / separates items within each of these delimiters:

All values to be suppressed in the printed matrix are entered within quotation marks between the symbols ⊥ and ⊤. However, MPR only suppresses true zeros. Thus, when decimal places less than the original value are selected, any non-zero decimal fraction that approaches zero (e.g. .00001) is printed as a non-zero number (i.e. .00…n). To suppress very small numbers, the original matrix should be modified with the operation ⌊ (i.e. floor):

In addition to value suppression, the global variables ∆NDEC, ∆PL, ∆LLEN, and ⎕PW can also be modified temporarily via the left argument. Here, the symbols ∩ and ∪ (i.e. cap and cup) are used to delimit environmental values from the row and column labels. The input syntax is ∆NDEC, ∆LLEN, ⎕PW, ∆PL, with the sequence of these variables always preserved. Thus, ∆NDEC, which sets the maximum number of decimal places within the matrix and rounds data accordingly, occupies the first place in the vector. The default setting for this variable is 2. To change this setting, the user need only enter the desired number of maximum decimal places within the delimiting symbols.

The defaults for each of the remaining settings are as follows: ∆LLEN, which sets the length of the row and column labels, equals 10; ⎕PW, which sets the page width, equals 80; and ∆PL, which sets the maximum number of rows in each formatted block, equals 50. For these settings, a negative number must be entered as a placeholder for each variable that will retain its default. For example, the vector ¯1 24 ¯1 ¯1 sets the maximum length for row and column labels for this print call to 24 without changing any of the other default settings; and 6 15 100 ¯1 changes the maximum number of decimal places to 6, label length value to 15, and the page width to 100 (the page width selected must correspond to the width of the printer. If the printer is only 80 columns wide and 100 columns are requested, the remaining 20 columns will be wrapped) without altering the default maximum number of rows per block:

Dyadic input of variables containing labels and default settings

MPR also accepts values to be suppressed through the left input string. In fact, the optional left argument can be used simultaneously to input row and column labels, default settings, and value suppression:

     ¯1 ¯1∪⊥0⊤' ∆MPR MATRIX

                  SS1      SS2      SS3      SS4      SS5      SS6      SS7

GENDER       114.2750 223.7000  95.9250 271.2250 291.5250 229.7750 245.2250

In this way, the settings for a particular project can be easily altered without modifying the existing defaults. Some examples of these changes are displayed below:

============================================================================
       Option              Global    Default     Delimiters*      Example
============================================================================
Row Labels                   --     R1,R2,...Rn  '⊢X⊣'          '⊢/WEEK1/WEEK2⊣'

Variable-Row Labels          --     R1,R2,...Rn  'X'            'ROWLABELS'
Variable-Column Labels       --     C1,C2,...Cn  ' X'**         'COLUMNLABELS'
Variables-Row & Column       --     R1,Rn..C1,Cn 'X Y'          'ROW COLUMN'
