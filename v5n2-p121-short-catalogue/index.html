Short Catalogue

Vector 5:2, page 121

APL community

Transcribed from the printed issue; not yet reviewed. Read it in the PDF of the issue, page 121

DISK 1¶

Title: The game of LIFE SIZE = 113K Donor: Paul Chapman
Description: Fast, large universe version of Conway's LIFE Hardware required: PC with IBM mono, IBM colour or Herc mono board. July 1986

DISK 2¶

Title: Fluctuation analysis SIZE = 9K Donor: Claude Bastian
Description: Fluctuation analysis for multichannel spectra. PC Software required: APL*PLUS PC July 1986

DISK 3¶

Title: Free software from APL385 SIZE = 282K Donor: Adrian Smith
Description: DOS file lister, expert system shell, screen design, Epson downloads, digital clock, APL utils, etc. PC Software required: APL*PLUS PC July 1986

DISK 4¶

Title: Piano SIZE = 4K Donor: Gerard Langlet
Description: Simple piano-playing in APL Hardware required: PC Software required: APL*PLUS/PC July 1986

DISK 5¶

Title: Pianoman SIZE = 355K Donor: Stuart Yarus *SHAREWARE*
Description: Very sophisicated piano-playing July 1986

DISK 6¶

Title: FRAME SIZE = 69K Donor: Robert Pullman
Description: Multidimensional numeric array editor. PC Software required: Sharp APL/PC July 1986

DISK 7¶

Title: Get/Put files SIZE = 21K Donor: M Kent
Description: Access filed data by name, not component number. Software required: APL*PLUS/PC July 1986

DISK 8¶

Title: Binary Combinations SIZE = 3K Donor: Otway Pardee
Description: Fast way to get binary image of combinations. Software required: APL*PLUS/PC July 1986

DISK 9¶

Title: Workspace Lister SIZE = 16K Donor: Roger Harper
Description: List vars and fns with index and pagination. Hardware required: PC, Epson LQ1500 printer. Software required: APL*PLUS/PC July 1986

DISK 10¶

Title: TEXT SIZE = 343K Donor: Ian Feldberg
Description: Typesetting for the IBM PC (needs DISK 11). Software required: APL*PLUS/PC July 1986

DISK 11¶

Title: PCPAK SIZE = 33K Donor: Ian Feldberg
Description: GRAPHPAK for the IBM PC. Software required: APL*PLUS/PC June 1986

DISK 12¶

Title: Functions for Linear Algebra SIZE = 57K Donor: Garry Helzer
Description: Functions from Helzer's book Applied Linear Algebra. Software required: APL*PLUS/PC July 1986

DISK 13¶

Title: DOS utilities SIZE = 57K Donor: Timo Kiravi
Description: View text files, mass copy, DISK directory, command line editor. July 1986

DISK 14¶

Title: Translate APL SIZE = 311K Donor: Wayland Products
Description: APL to Reverse Polish Translation. Software required: DOS 2.0, APL*PLUS, IBM, SHARP or PortaAPL. July 1986, April 1987

DISK 15¶

Title: RL2 Model 2, Version 3 SIZE = 359K Donor: Wayland Products
Description: Reverse Polish APL Model written in APL. April 1987

DISK 16¶

Title: F83VEC Demo SIZE = 320K Donor: Wayland Products
Description: FORTH extended to use APL symbols. Software required: DOS 2.0 or higher. July 1986, April 1987

DISK 17¶

Title: Migrate APL SIZE = 268K Donor: Wayland Products
Description: Migrates APL Workspaces to and from DOS files and can print them on NEC Spinwriter printers. Software required: Sharp, IBM, Porta or APL*PLUS. February 1987, April 1987

DISK 18¶

Title: FFILES SIZE = 48K Donor: A N Wiggins
Description: Component files for APL2 using AP121. Hardware required: MAINFRAME, PC Software required: APL2, APL*PLUS/PC March 1987

DISK 19¶

Title: CAVEDOS SIZE = 83K Donor: Mark Bassett
Description: Adventure front-end to DOS. Software reqd: APL*PLUS/PC 6.0 March 1987

DISK 20¶

Title: VecRL Command File SIZE = 210K Donor: Wayland Products
Description: APL style Reverse Polish vector language Hardware required: IBM PC, NEC Spinwriter, optional STSC ROM. Software required: DOS 2.0 April 1987

DISK 21¶

Title: Christmas 1986 SIZE = 346K Donor: Wayland Products
Description: 16 Christmas Carols played by PortaAPL or VecRL. April 1987

DISK 22¶

Title: User-Supported APL Software DemoDISK *DEMODISK* SIZE = 275K Donor: Dick Holt
Description: Sampler/demo of six user-supported workspaces. Software required: STSC APL*PLUS PC v3.0+ May 1987

DISK 23¶

Title: RAMFONT SIZE = 63K Donor: Adrian Smith
Description: APL fonts and font editors for Herc+ and EGA cards. Hardware required: IBM PC with ECM/EGA or Herc+ mono. Software required: APL*PLUS/PC June 1987

DISK 24¶

Title: Uniware Demonstration DISK SIZE = 360K Donor: Uniware
Description: Demonstration of Unitab and The APL Debugger. July 1987

DISK 25¶

Title: APL*PLUS/PC Demonstration DISK SIZE = 309K Donor: Cocking & Drury
Description: Demo of the dominant APL interpreter for the PC Hardware required: IBM PC and compatibles, PS/2. 384K minimum memory. August 1987

DISK 26¶

Title: STATGRAPHICS Demonstration DISK SIZE = 306K Donor: Cocking & Drury
Description: Demonstration of the most comprehensive statistical & graphics package for PCs Hardware required: IBM PC & compatibles, PS/2. August 1987
