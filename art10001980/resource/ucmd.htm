UCMD FILES

This page describes the files available as part of the Dyalog APL UCMD system by Ray Cannon.

Installation instructions for the suite as a whole are to be found here (A windows HELP file of about 230K).

A compressed file of the complete UCMD directory is located here (A PkZipped file of about 600K).
