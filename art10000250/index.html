APL 2000 User Conference, Orlando, November 14th-17th 1999 — Abstracts

Vector 16:2, page 7

conference reports

Transcribed from the printed issue; not yet reviewed. Read it in the PDF of the issue, page 7

Plenary Presentations¶

Cognos Corporation — A New Day For APL, Jim Sinclair, Vice President, Cognos Inc.

SoftMed Systems — Building A Company On APL, Don Segal, President and CEO, SoftMed Systems.

Finac — The Use Of APL in the Colombian Banking System, Luis Caro, President, Finac Ltda.

Training Sessions¶

Introduction to APL, Ray Polivka. Learn APL via the "See and Do" approach. This course introduces a major portion of the APL programming language. Attendees will learn how to create functions and variables and work with many of the APL primitives available. No previous APL knowledge is required.

Introduction to APL GUI Programming, Rick Butterworth. This course is designed for APL Programmers new to Windows. Learn how to build Windows applications or enhance your existing applications. Includes objects, properties, methods, events, and message driven architecture.

APL On The Internet, Fred Waid. Learn how to access the World Wide Web from your APL applicatioin. Make your existing applicaitions Web Aware and let your users access them from any brower over the Internet. Manipulate data from any web site and incorporate that information into your application.

ZarkWin Class, Gary Bergquist. ZarkWin is software for quickly building Windows input forms. Patterned after the popular Screen Interface Toolkit of APL+DOS, ZarkWin was developed by Zark Inc. to allow rapid interactive form design. Forms can be built, tested, and modified with no knowledge of ⎕WI

Com Objects and APL+Win, Patrick Parks. An Introduction to using Component Object Model (COM) which allows various Windows applications (such as Word and APL+Win) to work together.

Intermediate APL+Win Programming, Rick Butterworth. Using the powerful controls like Tree, Listview, Selector and MDI Forms. ActiveX Controls; Use Formula One SpreadSheet (Evaluation copy distributed).

WCALL, Brian Chizever. This sessions teaches how to call the Win32 Application Program Interface (API) and any other function in any 32 bit DLL from APL+Win.

APL+Win 3.5 Objects Collection, Eric Lescasse. Demonstrates a new product called "APL+Win 3.5 Objects" from Lescasse Consulting. This product is a collection of over 70 User Defined Objects using the latest APL+Win object technology.

Excel, Eric Baelen. Create multipage Excel workbooks from APL complete with formatting and graphics.A suite of functions to do all of the common Excel functions is provided. The session will end with a repeat of "Using Excel as a Front End to APL Applications".

Conference Papers¶

Using APL+Win 3.6, Eric Baelen. An in depth discussion of using the new features available in APL+Win version 3.6.

Building UDCs, Marvin Renich. User Defined Controls (UDCs) is a powerful addition to the APL Windows platform, but care must be taken to gain the maximum benefit from this ability. Learn the good habits of control builders.

Taking the Migraine out of Migration, Walter G. Fil. A discussion of the considerations of moving a DOS or Mainframe application to Windows. A utility (Qwin) has been created to make the process much easier.

Resource DLL Compiler, Brian Chizever. Make your application more professional by including all of your bitmaps, icons, wav files in a single resource file. All of the tools needed to create a resource DLL and examples of its use.

The Nature And Perils Of Floating Point Calculations In APL, Mark Osborne. When 2×2 doesn’t equal 4:

      .2×.2
0.040000000000000008

Porting Mainframe APL Applications to PC, Adam Kertesz and Steve Halasz. This session shares the lessons learned during the conversion process of porting a client’s mainframe APL application to the PC using Qwin.

Managing Long Running Calculations, Rick Butterworth. Learn to interrupt long running calculations with the options to display intermediate results, resume or cancel without lost work.

APL + CD, John Walker. Learn the basics of Internet communications as you build an application to get CD Album Titles, Artist Name and Track Names from the World Wide Web.

Characters, Codes, Glyphs, Fonts and Unicode, Bill Rutiser. An introduction to the representation, processing, exchange and display of non-ASCII text such as APL characters.

The 14 Myths of APL, Gary Bergquist. APL has been called a dead language. This fatalistic view lingers because of the general acceptance of 14 myths pertaining to APL. In this talk, the myths are presented and dispelled, laying bare the future prospects of APL.

Open Here, Fred Waid. A web site completely written in APL. Learn the tricks and techniques of its construction and how you can benefit from it.

An Outsider’s View of the Inside of Nested Arrays, Roy Sykes. Knowing how APL stores nested arrays can help you use them more efficiently. Roy covers the internal representation of arrays and gives general guidelines as to the tradeoffs in using them.

APL+Win and MS Access, Jeremy Main. Use the Microsoft Jet Database Engine from APL+Win to create, update and edit a .MDB file including changing table definitions, bulk update, and managing transactions.

Making It To Paper, Marvin Renich. A set of utilites to control various aspects of printing from Listview, Treeview or RichEdit controls. Control orientation, copies, paper tray, etc.

What Makes A Good Web Site? Carl House and Adrian Smith. Carl uses Causeway’s NewLeaf and HTM2000 workspaces for compiling approximately 4000 web pages from databases and other source materials. Carl will discuss design criteria for a good web site, how to promote it, and how to measure its effectiveness. Adrian will introduce the HTM functions, which are freely downloadable from the Causeway website, with supporting documentation taken from articles in Vector 13.4 onwards.

ADO, Warren Baelen. The ActiveX Data Objects (ADO) programming model is Microsoft’s strategic, high-level interface to all kinds of data. Learn the basics of ADO and how to access it from APL.

Managing APL Code, Patrick Parks. Methods to use commercially available code management systems with APL based workspaces is discussed. Sample functions for one such system are provided.

UDC, Eric Lescasse. A look into the creation of a suite of User Defined Controls by Lescasse Consulting.

An Excel Front End for APL+Win Applications, Eric Baelen. Version 3.6 of APL+Win now supports events from Excel so it can be more easily used as a front end to an APL application. A sample application is presented.

Creating a User Interface: Evolution or Intelligent Design? Colyn Phillips. A look at a real-world case of creating the user interface to select options for a product’s new feature.

Polymorphic APL Control (Fld): the Ultimate UDC, Jeff Pedneau. Build all of your application’s screens using UDCs, and wrapping them up inside a "container" control (Fld), and a few buttons.

APL and Powerpoint, Tom Atkins. Use APL+Win to control a Powerpoint presentation. Add MSAgent characters and interactive forms to hold users’ attention.

Getting the Most From APL and User Commands, Jim Weigang. User commands improve programmer productivity. Tools for linking command files together, displaying differences, tracking changes, and paging commands in a run-time application are described.
