Numeric Integration & Probability

Vector 1:2, page 117

mathematics and statistics

Transcribed from the printed issue; not yet reviewed. Read it in the PDF of the issue, page 117

by Professor Alan Hawkes

At school we learned a lot of clever tricks to integrate a wide class of functions f(x) to get a definite integral

∫ab f(x)dx

Unfortunately, there is an even wider class of functions which occur frequently in all branches of science and engineering for which no algebraic solution can be found in terms of known simple functions. This is certainly the case in statistics, where if f(x) is a probability density function the above integral represents the probability of an observation falling in the interval (a,b). In such cases one must resort to numerical integration techniques to get numerical answers. Often the results are tabulated for users to look up, such as the normal, t, chisquared, and F distributions which are so commonly used in statistics and found in e.g. Biometrika Tables by Pearson and Hartley (1958).

A lot of ingenious methods were developed to get good approximations with as little calculation as possible, using analytical techniques to place error bounds on the results. Biometrika and other tables were computed to very good accuracy, with great skill and dedication, using the famous Brunsviga hand calculating machines. With modern computers, especially using APL, it is so easy to calculate the function over a large grid of points that simple techniques will be perfectly adequate for most purposes, and accuracy may be controlled simply by repeating the calculation over a finer grid to see if results differ by less than some prescribed accuracy; if so, stop, otherwise make the grid finer again.

The simplest well known technique, the trapezium rule, approximates the function by series of straight lines. Very nearly as simple, and usually quite a bit more accurate for the same grid size is Simpson’s rule. If the interval (a,b) is divided up into 2M intervals with division points at

a = x0 < x1 < x2 … < x2M = b

the function f(x) is approximated by quadratic curves, rather than straight lines, over each pair of intervals (x0,x2) (x2,x4)… . This leads to the approximate integral

∫ab f(x)dx ≑ f(x0) + 4f(x1) + 2f(x2) + 4f(x3) + 2f(x4) + … + 4f(x2M−1) + f(xM)

The APL function Y NUMINT X enables one very easily to carry out numerical integration using Simpson’s rule for any well behaved function (one which is unbounded, for example, would need special treatment). The full specification of the right argument is a three element vector X←A,B,N. The result is then an N-vector containing the integral of the function over each of N equal subintervals into which the interval (A,B) is divided; e.g. if X←1 5 2 the result consists of the integral over (1,3) and the integral over (3,5). If N is omitted, so that X←A,B, it is automatically assumed that N←1 and the result is simply the integral over the whole range (A,B). If X contains a single item only, X←B we assume A←0 and N←1 so that the result is the integral over (0,B).

The function that is to be integrated is specified by the left argument Y in the form of a string vector. The usual form taken by Y will be the name of a function with an optional left argument to specify the shape if required. The function is expecting a vector as its right argument and returns as a result a vector of the same shape, containing the value of the function at each point of the input vector. The string is catenated with an appropriate 'GRID' in line [21] and executed, ⍎ ; this is also done with a different value for GRID in line [23]. In general one thus has a statement of the form 'A functionname' NUMINT X, with A a shape parameter vector.

2 Examples Using the Normal Distribution¶

The probability density function, pdf, of the standard normal distribution is given by

f(x) = (1 ÷ √2π) e−x²/2

This is calculated for each element of the vector X by the function NORMALPDF X. As an example the probability attached to the interval (1.5,2.4) say is

∫1.52.4 f(x) dx which is calculated by

      )DIGITS 4
      'NORMALPDF' NUMINT 1.5 2.4
0.0586

while

      'NORMALPDF' NUMINT 1.96
0.475

is the probability over the interval (0, 1.96). The probabilities for the three intervals (0,1), (1,2), (2,3) can be found from

      'NORMALPDF' NUMINT 0 3 3
0.3413  0.1359  0.0214

For the normal distribution the probability of the random variable X being less than a given value x > 0. can be written as P(0 < X < x)+½. This can be computed for each x = 1, 2, 3, 4 say by

      )DIGITS 7
      0.5 + + \'NORMALPDF' NUMINT 0 4 4
0.8413447  0.9772499  0.9986501  0.9999683                   - (1)

which agrees exactly with results in Table 1 of the Biometrika Tables.

The accuracy of integration is controlled simultaneously for all intervals over which the integral is required by a global variable ∆INTERR which was set at 1E¯7 for all the above examples. Suppose now we go right up into the tail and require the probability for each of the intervals (14,16), (16,18) and (18,20)

      )DIGITS 4
      'NORMALPDF' NUMINT 14 20 3
1.833E¯44  1.712E¯57  2.933E¯72

Now these are very much smaller than the accuracy setting, so we should not be surprised if these were not too good. If now we let

      ∆INTERR←1E¯50     and try again
      'NORMALPDF' NUMINT 14 20 3
7.794E¯45  6.389E¯58  9.741E¯73                               (2)

That’s much better, these are known to be correct to four figures.

In principle it would be a good idea to make ∆INTERR smaller still to cope with some of the very small values. However, with ∆INTERR←1E¯60 this soon leads to WS FULL! The reason is that at this level of accuracy the grid has to be very fine indeed over intervals for which the integral is relatively large. The moral of this is you should not simultaneously use intervals over which the values of the integral vary by a very large amount, and that ∆INTERR should not be made much smaller than you really need it. In isolation, with ∆INTERR←1E¯80

      'NORMALPDF' NUMINT 18 20
9.741E¯73

works perfectly well. The WS FULL problem previously was obviously due to the first interval.

These calculations were done on a PRIME 750. If you are working on a much smaller machine you would run out of space quicker. In that case you may prefer to take a different approach and approximate the integral by a suitable algebraic function. In the case of normal distribution this is done in Hawkes (1982) and is implemented in the function NORMTAIL X. This is known to be accurate to at least four significant figures, so for example compute

      (¯1↓Z) - 1↓Z← NORMTAIL 14 16 18 20
7.793E¯45  6.388E¯58  9.741E¯73
      )DIGITS 7
      1 - NORMTAIL ⍳4
0.8413451  0.9772489  0.9986502  0.9999683

These should be compared with results (2) and (1) respectively which are accurate to the number of figures shown. The approximation in NORMTAIL is good enough for most purposes and requires less workspace than using NUMINT (although it is not faster).

3 Some More Distributions¶

The shape of the probability density of student’s t distribution depends on a parameter known as the degrees of freedom, DF. This is calculated at a vector of points X by the function DF TPDF X. Then for the t distribution with 5 degrees of freedom say we can find

      )DIGITS 5
      0.5 + \'5 TPDF'NUMINT 0 4 4
0.81839  0.94903  0.98495  0.99484

which agrees exactly with the results in Biometrika Table 9. Again exact agreement with Biometrika Table 7 is found from the chisquared distribution with 12 degrees of freedom.

      1 - + \ '12 CHISQPDF' NUMINT 0 24 4
0.91608  0.44568  0.11569  0.02034

which are the probabilities of exceeding 6, 12, 18, and 24 respectively.

The chisquared distribution is a special case (α = DF/2, λ = ½) of the gamma distribution which has pdf

f(x) = λαxα−1 e−λx/Γ(α) , x>0 .

This is computed in A GAMMAPDF X where A is a two element vector containing values of α and λ.

Note that if α<1, you need to be careful not to include zero in any interval to be integrated over because the function tends to infinity. If α = 1 we have the well-known negative exponential distribution

f(x) = λe−λx , x > 0 .

Of course, we do not really need to use numerical integration on this one, but it can be done very simply, e.g.

      '0.5×*-0.5×' NUMINT 0 8 4
0.63212  0.23254  0.08555  0.03147
      '1 0.5 GAMMAPDF' NUMINT 0 8 4
0.63212  0.23254  0.08555  0.03147

of course gives exactly the same result. The former version, however, is interesting because it is done with only raw APL in the left argument.

Our range of basic probability distributions is completed by the F distribution and the Beta distribution, each having a left argument which is a vector of 2 elements.

      '6 10 FPDF' NUMINT 5.39
0.99003
      '325 577 BETAPDF' NUMINT .36 .38
0.39577

in agreement with p.44 of Soper (1921), evalutes the integral

∫.36.38 xa−1(1−x)b−1 ÷ B(a,b) dx

for a = 325, b = 577. Again note that there may be difficulties at x = 0 and/or x = 1 if a and/or b is less than unity

Of course a, b are not restricted to integers

      '16.1 5.2 BETAPDF' NUMINT 0.6
0.05671

agrees with the result on p.17 of Soper.
