Project rules
=============

Reviews and responses
---------------------
Reviews and reponses are **appended** to the current day's review file; i.e. `reviews/YYYY-MM-DD.md`, where `{YYYY-MM-DD}` is today's date. 

Maintaining chronological order is essential for multiple review-response rounds, so you may only **append** to the tail of the file and **never** insert into or otherwise alter what has already been written on it.

Before writing a review or a response, read the H1s and H2s in the current review file. If they are not in chronological order, report the problem and do nothing more.

Begin a review with an H1: `# Review: {subject} {HH:MM}` where `{HH:MM}` is the timestamp.

Begin a response with an H2: `## Response: {subject} {HH:MM}` where `{HH:MM}` is the timestamp.

Take timestamps **from the system clock** – never guess or estimate them.
