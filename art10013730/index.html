MicroAPL Ltd¶

The Windows version of APLX64, MicroAPL’s new 64-bit version of APLX announced in Vector 21.4, is now ready for beta testing. We are looking for further beta testers, so please contact us if you would like to participate in this programme. To run the software, you will need a PC with an AMD 64-bit processor (Athlon, Turion, or Opteron), or an Intel Xeon with EM64T or Pentium 4 with EM64T. You will also need to install Windows XP Professional x64 Edition (currently available in a free trial version from Microsoft).

Meanwhile, we are introducing a new low-cost student edition of APLX, and we have also issued a maintenance release (3.0.9) of APLX for Windows, Linux and MacOS. This fixes a number of minor problems. It is a recommended upgrade for existing users of APLX Version 3, who can download it free of charge from our website.

Kx Systems¶

A new kdb+ White Paper is available on kx.com. With tick data volumes continuing their out-of-sight escalation, an end-to-end high-speed database is more essential to competitive advantage than ever. To get the details on how kdb+ offers a unified view of streaming, in-memory and historical data, please download the new kdb+ white paper.

Kx and Intel co-sponsor Realtime Data event in London¶

In October Kx and Intel co-sponsored a seminar on “Trends in Real-time Data” organized by Lepus, a consultancy specializing in financial services research. Lepus is currently preparing a white paper on the topic. If you’d like us to notify you when it is available, please contact us.

New kdb+ applications from First Derivatives.¶

FD now offers three new applications for kdb+. QDBA is a database administration and development tool that provides a development interface to the power of kdb+. Kdb+fix offers a framework supporting client applications for different sell-side FIX engines. Program Trading Platform provides a set of tools to support algorithmic trading. For more information contact Michael O’Neill.
