End of session
==============

I will announce the end of a work session, usually with "let's wrap up".

Append to `progress/YYYY-MM-DD.md` a summary of the work done. 
If this is not the first session of the day, prefix the summary with an H2: `## Session ending {HH:MM}`.

Update `TODO.md` with the expected next steps for the project.

Commit all changes to `plans/`, `progress/`, `reviews/` or `README.md`.


Branches
========

Raise an issue on the remote for any substantial work, and do it in a Git branch. Include relevant changes to plans, progress and review documents.

Planning work that changes **only** plan, progress and review documents **may** be committed to the `main` branch.


Permissions
===========

You may read anything in the project folder.

You may **never** write in the `sources/` folder.

In the `reviews/` folder you may write **only** in the current day's review file, as described in `project-rules.md`.

Other rules
===========

The rules in `project-rules.md` apply to you.
