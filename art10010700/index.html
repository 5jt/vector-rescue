The Common Mean, Non-negative Definite Matrices, and APL

Vector 12:1, page 107

mathematics and statistics

Transcribed from the printed issue; not yet reviewed. Read it in the PDF of the issue, page 107

by Dietrich Trenkler (University of Osnabrück) and Götz Trenkler (University of Dortmund)

Introduction¶

In a recent contribution to Education Vector De Kerf [3] advocated the use of the common mean as an alternative to the geometric mean and the arithmetic mean. If x0 is the smaller of two positive numbers x0 and y0, the geometric mean of these numbers is x1 = √(x0y0) while their arithmetic mean is y1 = (x0 + y0)/2. If the procedure of forming geometric and arithmetic means is repeated indefinitely so that

xi+1 = √(xiyi) and yi+1 = (xi + yi)/2,

where i = 1,2,…, one obtains

x0 ≤ x1 ≤ x2 ≤ ··· ≤ xi ≤ ··· ≤ yi ≤ ··· ≤ y2 ≤ y1 ≤ y0,

and there is convergence to a common mean c(x0,y0) of x0 and y0.

In the following it will be shown that this notion of a mean can be generalized to nonnegative definite (n.n.d.) matrices, provided some assumptions are met. Note that the arithmetic, harmonic and geometric mean of nonnegative definite (n.n.d.) matrices has already been discussed in the literature, e.g. Anderson and Duffin [1].

Theory¶

Consider two n.n.d. matrices X0 and Y0 of type n × n such that X0 and Y0 commute, i.e. X0Y0 = Y0X0. Since both matrices are also symmetric, there exists a simultaneous diagonalization of X0 and Y0 by an orthogonal matrix P, that is

X0 = PΛP′,   Y0 = PΩP′,   (1)

where Λ = diag(λj(X0)) and Ω = diag(ωj(Y0)) is the diagonal matrix of eigenvalues of X0 and Y0, respectively. This will be demonstrated in the section "Algorithm and Programs". Furthermore, we assume that

λ1(X0) ≤ ··· ≤ λn(X0) and ω1(Y0) ≤ ··· ≤ ωn(Y0).

Consider now the following sequence of matrices

X1 = (X0Y0)½   Y1 = (X0 + Y0)/2
Xi+1 = (XiYi)½   Yi+1 = (Xi + Yi)/2   i = 1,2,….

Observe that since X0 and Y0 commute, X0Y0 is an n.n.d. matrix, and the square root X1 of X0Y0 is given by

X1 = P(ΛΩ)½P′ = Pdiag(√(λj(X0)ωj(Y0))) P′.

By induction it is readily shown that the Xi and Yi are well defined and n.n.d. Furthermore Xi and Yi commute, and

Xi = PΛiP′,   Yi = PΩiP′,

where Λi = diag(λj(Xi)) and Ωi = diag(ωj(Yi)). If λij and ωij denotes the j-th diagonal element of Λi and Ωi, respectively, it can be readily seen that

λ1j = √(λj(X0)ωj(Y0))   ω1j = (λj(X0) + ωj(Y0))/2
λi+1j = √(λijωij)   ωi+1j = (λij + ωij)/2

for i = 1,2,… and j = 1,…,n. Let now c(λj(X0),ωj(Y0)) denote the common mean of λj(X0) and ωj(Y0). Then obviously the sequence of matrices (Xi,Yi) converges to a common matrix mean C(X0,Y0) given by

C(X0,Y0) = Pdiag(c(λj(X0),ωj(Y0)))P′,

which might be considered as a competitor to the geometric mean X1 = (X0Y0)½ and the arithmetic mean Y1 = (X0 + Y0)/2 of the matrices X0 and Y0.

Algorithm and Programs¶

In the following (assuming ⎕IO←1 throughout) we give a program that yields the orthogonal P mentioned in (1). It is based on the following:

Let A and B be k × k symmetric matrices. A necessary and sufficient condition that an orthogonal matrix P exists such that P′AP and P′BP are each diagonal is that AB = BA (or AB is symmetric).

cf. Graybill [4], pp. 406–7. The following algorithm is extracted from the proof of this theorem.

(i) Compute an orthogonal matrix R such that R′AR = D where D is diagonal.

(ii) Assume that D can be written as

    ⎛ λ₁I₁   0    ···   0    ⎞
D = ⎜  0    λ₂I₂  ···   0    ⎟
    ⎜  ⋮     ⋮     ⋱    ⋮    ⎟
    ⎝  0     0    ···  λₘIₘ  ⎠

(iii) Set C = RBR′. It follows that C is of the form

    ⎛ C₁₁   0   ···   0   ⎞
C = ⎜  0   C₂₂  ···   0   ⎟
    ⎜  ⋮    ⋮    ⋱    ⋮   ⎟
    ⎝  0    0   ···  Cₘₘ  ⎠

where Cii is k × k whenever Ii is k × k. If each Cii consists of exactly one element C is diagonal and the algorithm stops by setting P=R. Otherwise, we have to obey (iv)–(vi).

(iv) Find orthogonal matrices Qj for j = 1,2,…,m such that Q′jCiiQj is diagonal.

(v) Set

    ⎛ Q₁   0   ···   0  ⎞
Q = ⎜  0   Q₂  ···   0  ⎟          (2)
    ⎜  ⋮   ⋮    ⋱    ⋮  ⎟
    ⎝  0   0   ···  Qₘ  ⎠

(vi) Finally, P = RQ is such that P′AP and P′BP are each diagonal.

It is readily seen that there are two instances ((i) and (iv)) where we need the spectral decomposition of an n.n.d. matrix. This calls for the computation of eigenvalues and eigenvectors and since most modern APL2 systems offer workspaces with programs to find them we resort to them. For instance, APL*PLUS II provides a workspace EIGENVAL from which we took the program SYMEIG to compute the spectral decomposition of a matrix. This is done by VALVEC←SPECDEC MAT, where the first row of VALVEC are the eigenvalues MAT in ascending order and 1 0↓VALVEC is an orthogonal matrix P of eigenvectors. It uses the function STANDARDIZE to convert the columns x of a matrix to

y = x/√(x′x)   such that   y′y = 1.

    ∇R←SPECDEC M
[1] R←R[1;],[1]STANDARDIZE 1 0↓R←1 SYMEIG M
[2] R←R[;⍋R[1;]]
    ∇

    ∇R←STANDARDIZE M
[1] R←M×((⍴M)⍴+/[1]M×M)*¯0.5
    ∇

SIMDIAGMAT can be used to compute the orthogonal matrix P that diagonalizes X0 and Y0 simultaneously, cf. equation (1). It uses the function FREQUENCIES to find the frequencies of distinct elements in a vector and DIAGMATFROM to construct the block diagonal matrix Q given in (2).

    ∇P←A SIMDIAGMAT B:R:C:Q:QI:D:E:I
[1] Q←⍳0 ⋄ I←1
[2] C←(⍉R)+.×B+.×R←1 0↓SPECDEC A
[3] E←0,+\D←,1 0↓FREQUENCIES 1 1⍉(⍉R)+.×A+.×R
[4] LOOP:Q←Q,⊂1 0↓SD (2⍴D[I])↑(2⍴E[I])↓C
[5] →((⍴D)≥I←I+1)/LOOP
[6] P←R+.×DIAGMATFROM Q
    ∇

    ∇R←FREQUENCIES X;A
[1] A←A-¯1↓0,A←(R←(¯1↓X≠1⌽X←X[⍋X]),1)/⍳⍴X←,X
[2] R←(R/X),[0.1]A
    ∇

    ∇R←DIAGMATFROM M;I;A;B;C
[1] I←1
[2] M←(¯2↑¨(⊂1 1),¨⍴¨M)⍴¨M
[3] R←(R,R←+/A←,1 0↓⊃[1]⍴¨M)⍴0
[4] B←0,+\A
[5] LOOP:R[C;C←B[I]+⍳A[I]]←I⊃M
[6] →((⍴M)≥I←I+1)/LOOP
    ∇

X0 CMEANMAT Y0 computes the common matrix mean C(X0,Y0) of matrices X0,Y0 ↔ X0 Y0. It is based on the function CMEAN taken from De Kerf [3].

    ∇R←X CMEANMAT Y;P;L;O
[1] P←X SIMDIAGMAT Y
[2] L←1 1⍉(⍉P)+.×X+.×P
[3] O←1 1⍉(⍉P)+.×Y+.×P
[4] R←P+.×(DIAGMATFROM L CMEAN¨O)+.×⍉P
    ∇

Finally, to compute the arithmetic matrix mean and the geometric matrix mean we have

    ∇R←A AMEANMAT B
[1] R←0.5×A+B
    ∇

    ∇R←A GMEANMAT B;P;L;O
[1] P←A SIMDIAGMAT B
[2] L←(⍉P)+.×A+.×P ⋄  O←(⍉P)+.×B+.×P
[3] R←P+.×(( |L×O)*0.5)+.×⍉P
    ∇

Example¶

What is the common matrix mean of a matrix X0 and its inverse Y0 = X0−1? For instance, let X0 Y0 ↔ X0 Y0 where

     ⎛  2   0   1  −1  −2 ⎞         ⎛ 2   5   3   2  2 ⎞
     ⎜  0   2  −2  −1  −1 ⎟         ⎜ 5  27  17  11  8 ⎟
X₀ = ⎜  1  −2   4  −1  −1 ⎟    Y₀ = ⎜ 3  17  11   7  5 ⎟ .
     ⎜ −1  −1  −1   3   2 ⎟         ⎜ 2  11   7   5  3 ⎟
     ⎝ −2  −1  −1   2   4 ⎠         ⎝ 2   8   5   3  3 ⎠

X0 and hence Y0 are p.d. and X0Y0 = I which is the geometric mean of X0 and Y0. Accordingly they can be used to exemplify the new concept of a common matrix mean of two n.n.d. matrices. We get

      4⍕X0 CMEANMAT Y0
 1.3767   0.7982   0.6784   0.1113  ¯0.0731
 0.7982   5.3691   2.3040   1.5550   1.0720
 0.6784   2.3040   3.2190   0.9224   0.5988
 0.1113   1.5550   0.9224   2.0441   0.8833
¯0.0731   1.0720   0.5988   0.8833   1.9346

One is inclined to speculate on a relation like aij < cij < gij where A = (aij) is the arithmetic mean, C = (aij) is the common mean and G = (gij) is the geometric mean. However, for the example above we have

      5 1⍕X0 AMEANMAT Y0
2.0  2.5  2.0  0.5  0.0
2.5 14.5  7.5  5.0  3.5
2.0  7.5  7.5  3.0  2.0
0.5  5.0  3.0  4.0  2.5
0.0  3.5  2.0  2.5  3.5

so that a15 = g15 = 0 and c15 = −0.0731.

Concluding Remarks¶

In this paper we introduced a matrix generalization of the common mean, originally defined only for real numbers. Like the other means which already exist it might prove useful in statistics and matrix theory. Further research should focus on algebraic properties related to the common mean of n.n.d. matrices (cf. Anderson and Trapp [2]). From the construction of the sequences Xi and Yi it has become clear that

X0 ≤ X1 ≤ X2 ≤ ··· ≤ Xi ≤ ··· ≤ Yi ≤ ··· ≤ Y2 ≤ Y1 ≤ Y0

and X0 ≤ C(X1,Y0) ≤ Y0, where A ≤ B for matrices A and B means that B − A is n.n.d. It has also been investigated under which conditions the order relation "≤" can be substituted by "<", i.e. the corresponding differences are positive definite.
