There were two common mistakes made within ANAGRAM functions submitted. Thefirst was to forget to eliminate the duplicate permutations caused by redundantletters. For example, the permutations 'SMST'[2 4 1 3] and 'SMSI'[2 4 3 1] both returnthestring MISS.

The second mistake wasto assume you can avoid sorting the character matrix (to catch duplicates) by first sorting the character string. The assumption seems reasonablebutisn t. For example, the sorted permutations 'IMSS'[1 3 2 4], IMSS'[1 3 4 2] and 'IMSS'[1 4 2 3] return the unsorted strings ISMS, ISSM, ISMS.
