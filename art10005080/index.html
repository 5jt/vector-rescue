APL+Santa Fe Previewed at the APL2000 User Conference by Eric Lescasse

Introduction APL+SantaFe has been presentedin detail during the APL2000 2005 User Conference. Put in a few words, APL+SantaFe is a 100% .Net version of APL+. Here areits main characteristics:

* itis a completely new APL written for .Net * itis a pure Net language (as VB.Net and C#) * highly compatible with APL+Win,but about5 times faster and as fast as C# * with a few changesto iron the weaknesses of APL * with a LOTof extensions and improvements, new tools & new options * usable from within Visual Studio 2005 with intellisense, VS debugger, & everything available under Visual Studio 2005 * with still our so valuable Interactive APL Session ¢ with full access to Windows Formsandall .Net controls * with syntax extensions to allow copy/pasting C# code and makingit run with minimal changes « with access to the whole .Net Framework 2.0 * with multi-processor, multi-thread, 64-bit processor & huge memory space support ¢ with commonerror handling like C# and VB.Net * producing 100% managed code * producing APL .EXE and .DLL files which can be consumedby other .Net languages « allowing youto doreal Object Oriented programs (support for: namespaces, classes, methods, properties, events, inheritance, polymorphism) « many more enhancements

This article is a mixture of information taken from slides presented by APL2000at the Conference and from notesI have written down while looking at the APL+SantaFe demos.
